04 Tool 계약 흐름 — tool_wrap (Robo Duck 이식 · LangGraph act 노드 pre/post 훅)

phase-LLM은 등록 tool id만 고를 수 있고(닫힘), 실행은 tool_wrap 단일 경로. 예외는 CRSError로 승격되어 봉투로만 반환(누출 0 규율).

ToolCall{id, params}▶ pre_hook = Legality
requires∧consumes▶ 본체 = safe-exec 러너
(collector·수식·nsenter·shim)▶ DefOk[T] · action{stop}
post_hook = WorldState 갱신
produces·effect·applied()◀ success │ CRSError → DefErr
(★전 tool CRSError-only raise)◀ 실패/예외
닫힘 3중 강제 ① phase-LLM 출력 DefToolId pydantic 화이트리스트(밖=거부) ② Legality pre_hook(precond 미충족=비legal) ③ exec-binding만 실행(자유형 명령 0). = "등록된 대응만 집행".
